An autonomous program entry for the "One Line, One Laugh: Roast Your Fridge" bounty. It deterministically outputs a sharp, humorous single-line roast of a refrigerator.

## Program Entrypoint
`main.ts` deterministically outputs a single-line roast (`entry.txt`, 1 to 200 UTF-8 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR` (or `/output` if unset).
